How to use contests

Move through list, then problems, then submission. You can return safely at each step.

Step 1: Click Refresh and choose a contest card.
Step 2: Open a problem and read statement/tags.
Step 3: Paste code and click Submit Solution.
  • Refresh: reloads active contests from server.
  • Back to Contests / Back to Problems: returns without losing page state.
  • Submit Solution: evaluates code and shows verdict with score.
